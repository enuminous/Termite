# TERMITE Architecture

## Pipeline

1. Agent Registry
2. Topology Builder
3. Local Interaction Engine
4. Collective State Aggregator
5. Cluster/Fragmentation Analyzer
6. Perturbation Propagation Engine
7. Attractor Stability Analyzer
8. Topology Comparison Harness
9. Emergence Reporter

## Inputs

- agent states
- local update rules
- graph topology
- edge weights
- seeds
- perturbations

## Outputs

```json
{
  "collective_coherence": 0.84,
  "fragmentation": 0.12,
  "emergence_score": 0.37,
  "topology_sensitivity": 0.29,
  "local_global_amplification": 2.4,
  "converged": true
}
```

## Design principle

TERMITE distinguishes:
- many agents doing similar things
from
- a collective mode created by interaction.

## Integration

ORCA can assess explicit coordination inside the collective.

HORSE can include human agents in mixed teams.

JELLYFISH can map cascading failures across the agent network.

LYNX can identify genuinely novel collective behaviors.
